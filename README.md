# 白果TV 发布频道

一个体验超好的红果短剧电视版，强于原生大屏幕看短剧体验，横屏漫剧终极解决方案！

白果TV 红果短剧的安卓TV版本应用（Android 8.0+）的发布仓库

## 架构概要

- 原生 Android TV 客户端，单 APK，无自建服务端，不收集任何数据
- 内容数据来自公开内容平台的公开接口
- 播放设备身份在首次启动时自动生成并固化
- 收藏、观看进度、偏好全部保存在电视本机；换机通过手机扫码在本机与手机之间直传
- 应用内更新读取本仓库 `update.json`，下载后校验大小、SHA-256 与签名，再交由系统安装

## 功能介绍

**浏览与播放**

- 首页推荐、搜索、排行榜、片库分类，全部支持遥控器操作
- 最高 1080P 清晰度随时切换，支持倍速播放与画面模式调整
- 原生弹幕体验，包括原生Emoji支持
- 定时停止：按时间或看完指定的集数后自动停止

**连播**

- 超级连播（默认开启）：一集播完自动无缝衔接下一集，整季连播无感切换；就算是切成每集30s，也能一口气无缝看俩小时！
- 自动连播：一集播完自动播放下一集
- 自动下一季：能自动识别季信息，一季播完自动进入下一季，等待时间可在 5–15 秒之间调整
- 换集时显示集数（默认开启）：切换集数时左上角短暂显示当前集数与总集数
- 播放菜单 10 秒无操作自动淡出，不遮挡画面

**追更与记录**

- 收藏追更：收藏喜欢的剧，有新集时显示「+N 集」，有新季时显示未看的季数，首页「收藏更新」汇总提醒，类似预约新季提醒
- 继续观看：自动记录每集观看进度，下次打开接着看
- 稍后看：想看的剧先记下来，之后从首页进入
- 最近观看与搜索历史

**数据与更新**

- 收藏、进度、偏好全部保存在电视本机，不收集任何数据
- 手机扫码备份与恢复，换机不丢记录
- 应用内自动更新，新版本下载后自动校验再安装

## 下载

在 [Releases](https://github.com/zqs1qiwan/baiguotv-release/releases) 页面下载最新正式版 APK。

## 应用内自动更新

- 打开应用后自动检查一次新版本；也可以在「设置 → 版本与更新」手动检查
- 发现新版本后自动下载并校验，确认后由系统覆盖安装，本机数据保留
- 检查清单地址：`https://github.com/zqs1qiwan/baiguotv-release/releases/latest/download/update.json`

## 发布物

| 文件 | 说明 |
| --- | --- |
| `baiguotv-<版本>-android8.apk` | 正式版安装包（签名 + 代码混淆） |
| `update.json` | 应用内更新清单（schema 1） |
| `SHA256SUMS` | 上述文件的 SHA-256 校验和 |

调试构建仅用于内部测试，不在本仓库发布。

## 设备身份

应用首次启动会自动生成设备信息并保存在本机（播放接口接受新生成的设备号），无需手动激活即可使用。
后续可能需要真实用户身份 用户自带设备id等方式使用（目前还不需要）

## 关于文档详细程度

客户端特征、协议参数与签名实现细节不在本文档公开：这些内容一旦公开，容易被批量识别并遭到针对性封禁，最终影响所有使用者的可用性，因此刻意省略。
